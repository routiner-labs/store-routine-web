# 사장 스케줄 헤더 검색·세부검색 설계

## 목표

기본 스케줄과 일자별 조정 화면의 검색을 다른 사장 목록 페이지와 같은 헤더 우측 구조로 통일하고, 지정한 근무 시간 범위에 실제로 근무하는 직원만 찾을 수 있게 한다.

## 기준 화면

- `owner/employees`: 헤더 우측 이름 검색, 검색 버튼, 세부검색 토글과 모바일 세부검색 패널
- `owner/documents`, `owner/requests`: 검색어 적용, 세부검색 활성 상태, 필터 초기화, 반응형 패널
- 스케줄 화면의 기존 편집표, 저장 영역, 기본·일자별 조정 상태 로직은 유지한다.

## 선택한 방식

### 표준 헤더 검색과 펼침형 세부검색

- 768px 이상에서는 헤더 우측에 `직원 이름 검색`, `검색`, `세부 검색`을 순서대로 배치한다.
- 768px 미만에서는 헤더 검색창과 검색 버튼을 숨기고 세부검색 버튼만 아이콘으로 표시한다.
- 세부검색 패널의 첫 행에는 모바일에서도 사용할 수 있는 이름 검색과 `필터 초기화`를 둔다.
- 두 번째 행에는 `근무 시간` 범위 입력을 둔다.
- 이름 검색은 다른 페이지처럼 Enter 또는 `검색` 버튼으로 적용한다.
- 시간 범위는 시작·종료 값을 초안으로 입력한 뒤 `적용` 버튼을 눌러 확정한다.
- 적용된 이름 또는 시간 필터가 있으면 세부검색 버튼을 활성 스타일로 유지한다.

팝업이나 별도 페이지보다 기존 펼침형 패널이 현재 제품의 검색 흐름과 가장 일관되고, 편집표의 세로 공간을 계속 사용할 수 있다.

## 시간 범위 필터 의미

시간 범위는 직원의 근무 구간과 검색 구간이 한 순간 이상 겹칠 때 일치한다.

```text
직원 근무: 09:00 ───────── 18:00
검색 범위:          17:00 ───── 19:00  → 포함
검색 범위:                  18:00 ─ 19:00  → 제외
```

- 겹침 조건은 `근무 시작 < 검색 종료 && 근무 종료 > 검색 시작`이다.
- 경계에서 끝나는 근무는 검색 범위 안에서 실제로 근무하지 않으므로 제외한다.
- 시작 또는 종료 중 하나만 입력된 상태에서는 `적용` 버튼을 비활성화하고 입력 완료 안내를 표시한다.
- 종료 시간이 시작 시간과 같거나 빠르면 `적용` 버튼을 비활성화하고 범위 오류를 표시한다.
- 필터 초기화는 이름 입력·적용 검색어·시간 범위를 모두 비운다.

## 모드별 근무 시간 기준

### 기본 스케줄

- 직원의 반복 기본 스케줄 `startTime`, `endTime`을 사용한다.
- 기본 스케줄이 없거나 근무 요일이 하나도 선택되지 않은 직원은 시간 범위 검색에서 제외한다.

### 일자별 조정

- 현재 선택한 날짜의 `effectiveDay` 결과를 사용한다.
- 일자별 조정이 있으면 조정 시간이 기본 스케줄보다 우선한다.
- 선택 날짜가 휴무이거나 기본 스케줄과 조정이 모두 없으면 시간 범위 검색에서 제외한다.
- 날짜를 바꾸면 같은 시간 필터를 새 날짜의 실제 근무 정보에 다시 적용한다.

## 검색 결합

- 이름 검색과 시간 범위는 AND 조건으로 결합한다.
- 이름이 일치하더라도 해당 시간 범위에 근무하지 않으면 표시하지 않는다.
- 필터는 화면에 렌더링할 직원만 변경하며 스케줄·일자별 조정 상태를 수정하거나 초기화하지 않는다.
- 검색 결과가 없으면 기존 편집표 안의 `검색 결과가 없습니다.` 행을 유지한다.

## 컴포넌트 경계

- `EmployeeScheduleManager.tsx`: 스케줄·조정 상태와 이벤트를 유지하고, 필터에 직원별 실제 근무 구간을 제공한다.
- `EmployeeScheduleHeader.tsx`: 뒤로가기·제목·데스크톱 검색·세부검색 버튼·세부검색 패널을 렌더링한다.
- `EmployeeScheduleHeader.module.css`: 헤더 검색과 펼침 패널의 표준 반응형 스타일을 담당한다.
- `useEmployeeScheduleFilters.ts`: 검색 입력, 적용 검색어, 패널 상태, 시간 범위 초안·적용값과 필터링된 직원 목록을 소유한다.
- `EmployeeScheduleTable.tsx`: 검색 UI 책임을 제거하고 편집표와 빈 결과 행만 렌더링한다.
- `EmployeeScheduleTable.module.css`: 기존 검색 도구 스타일을 제거하고 편집표 스타일만 유지한다.

헤더와 필터 상태를 분리해 300줄 제한에 가까운 `EmployeeScheduleManager.tsx`를 줄이고, 시간 겹침 규칙을 독립적으로 검증할 수 있게 한다.

## 접근성

- 헤더 검색 입력은 `헤더 직원 이름 검색`, 패널 검색 입력은 `세부검색 직원 이름 검색`으로 구분한다.
- 검색 버튼은 각각 `헤더 직원 검색`, `세부검색 직원 검색`으로 구분한다.
- 세부검색 버튼은 `aria-expanded`와 패널 `aria-controls`를 제공한다.
- 시간 입력은 `근무 시간 시작`, `근무 시간 종료` 이름을 제공한다.
- 범위 안내와 오류는 `role="status"`로 전달한다.
- 세부검색 패널이 접힌 상태에서는 내부 컨트롤이 키보드와 접근성 트리에서 제외된다.

## 검증

- 1440px에서 헤더 검색이 제목 오른쪽에 표시되고 이름 검색이 Enter와 검색 버튼으로 적용되는지 확인한다.
- 390px에서 헤더 검색은 숨고 세부검색 패널 안 검색만 사용할 수 있는지 확인한다.
- 기본 스케줄에서 `10:00~12:00` 검색 시 김민수와 박서준이 노출되고 이서윤과 스케줄 없는 최수아가 제외되는지 확인한다.
- `18:00~19:00` 검색 시 18시에 끝나는 김민수는 제외되고 이서윤과 박서준은 노출되는지 확인한다.
- 일자별 조정에서 선택 날짜의 휴무·조정 시간을 기준으로 결과가 바뀌는지 확인한다.
- 이름과 시간 범위를 함께 적용했을 때 교집합만 표시되는지 확인한다.
- 필터 초기화 후 활성 직원 4명이 복원되고 기존 편집 상태가 유지되는지 확인한다.
- 1440px, 768px, 390px와 라이트·다크 모드에서 패널·입력·오류·빈 결과와 가로 넘침을 확인한다.

## 제외 범위

- 근무 요일, 직원 상태, 전화번호 추가 필터
- 날짜 범위 검색
- 초성 검색과 오타 교정
- 검색어 URL 저장
- 야간 근무가 다음 날로 이어지는 시간 범위 검색
