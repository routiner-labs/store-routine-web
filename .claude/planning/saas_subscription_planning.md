## 1. 가격표 (확정)

모든 가격은 부가세 포함.

| 항목 | 가격 | 내용 |
|---|---:|---|
| 기본 | 월 9,900원 | 매장 1개, 기본 20GB, 직원 무제한, 모든 기능 |
| 매장 추가 | 매장당 월 8,800원 | 매장별 기본 20GB (2호점부터 할인 — 볼륨 할인 구조) |
| 용량 추가 | 10GB당 월 3,300원 | 매장별 귀속 (계정 공용 풀 아님) |
| 무료 체험 | 30일 | 신규 가입 시, 카드 등록 없음 |
| 연간권 | 11개월 가격 | 1개월 무료 (기본 매장 기준 연 108,900원), 매장 요금만 대상 |

- 직원 수 무제한. 퇴사자 계정 보존 포함 — 과금 기준이 용량이므로 좌석 제한을 두지 않는다.
- 기능 게이팅 없음: 체험/유료 모두 전 기능 사용 가능, 제한은 용량뿐.

## 2. 결제 주기 (확정)

- **매월 25일에 다음 달(1일~말일) 이용료를 선결제**한다.
  이 해석이어야 아래 정책들이 모두 성립한다: 결제 실패 시 "월초부터" 뷰어 제한(그 달 이용료가 미납이므로), 해지 시 "월말까지" 이용(그 달은 이미 결제됨).
- 중간 가입: 가입일부터 해당 월 말일까지 일할계산으로 즉시 결제, 이후 25일 정기 결제에 합류.
  - 세부(구현 시 결정): 25일 이후(26일~말일) 가입 시 남은 며칠 일할분과 다음 달 요금을 함께 결제할지 분리할지.
- 매장 추가/용량 추가도 동일 원칙: 추가 시점부터 월말까지 일할계산, 이후 정기 결제에 합산.
- 연간권: 12개월 이용에 11개월 가격.
  - 적용 대상: 매장 요금(기본 매장 + 추가 매장). **용량 추가는 연간 할인 없음** — 월간 과금만.
  - 중도 환불: 할인 전 정가(월 요금) 기준으로 사용 기간을 일할계산해 차감한 잔액을 반환.
    예: 기본 매장 연간권 108,900원 결제 후 4개월 사용하고 해지 → 환불액 = 108,900원 - (9,900원 x 4) = 69,300원.

## 3. 용량 정책 (확정)

- 산정 대상: **사진(증빙)과 파일(문서함·요청 첨부)만**. 텍스트 데이터(체크리스트, 요청 내용 등)는 제외.
- 초과 시: **사진·파일 업로드만 차단**, 그 외 기능(출퇴근, 체크, 요청 텍스트 등)은 정상 동작.
- **자동 추가 결제 금지.** 추가 용량은 사장이 직접 구매해야만 적용된다.
- (운영 권장) 80% / 95% 도달 시 사장에게 경고 알림.
- (원가 필수) 사진은 업로드 시 리사이즈/압축 저장 — 20GB의 실효 수명과 전송(egress) 비용을 좌우하는 최대 레버.

## 4. 결제 실패 / 해지 (확정)

### 결제 실패 흐름

```text
25일 결제 실패
  → 말일까지    : 정상 이용 유지, 재결제 시도 및 안내      (PAST_DUE)
  → 익월 1일    : 뷰어(읽기 전용) 모드로 제한              (SUSPENDED)
  → 14일까지 미결제
  → 15일부터    : 로그인 불가                              (LOCKED)
```

- 뷰어 모드는 계정 전체에 적용 — **직원도 동일하게 쓰기 불가**(출퇴근 기록, 체크 수행, 업로드, 요청 작성 등). 조회만 가능.
- 데이터 보존: **이용 종료 상태(LOCKED, 체험 종료 후 미결제)로부터 90일 보관 후 삭제.**
- 고지: 프로필 페이지 하단 푸터의 "데이터 처리 기준" 팝업으로 보관·삭제 기준을 상시 고지한다. (삭제 임박 시 개별 통지는 별도 운영 항목)

### 해지

- 해지해도 이미 결제된 월의 말일까지 정상 이용 가능, 이후 CANCELED.

### 구독 상태 모델 (LOCKED 추가)

```text
TRIAL       체험 중 (30일)
ACTIVE      정상 구독
PAST_DUE    25일 결제 실패 ~ 말일 (정상 이용, 재시도 중)
SUSPENDED   뷰어 모드 (익월 1일 ~ 14일)
LOCKED      로그인 불가 (15일 ~)
CANCELED    해지 (결제된 기간 만료 후)
```

## 5. 권한 구조 (확정)

- MVP의 결제/구독 주체는 **사장 1인 계정**. 사장 계정 하나에 n개 매장.
- 매니저 권한 구조는 이후 단계에 도입 예정 — 데이터 모델 설계 시 역할(role) 확장 여지만 남겨두고 MVP에는 넣지 않는다.

## 6. 확정된 세부 정책 (2차 결정 반영)

| # | 항목 | 결정 |
|---|---|---|
| 1 | 데이터 보존 | LOCKED 이후 90일 보관 후 삭제 (삭제 전 고지 운영 필수) |
| 2 | 연간권 | 매장 요금(기본+추가)만 연간 할인, 용량 추가는 월간만. 중도 환불은 할인 전 정가 기준 일할 차감 후 잔액 반환 |
| 3 | 체험 | 카드 등록 없이 30일 체험 |
| 4 | 뷰어 모드 | 직원 포함 계정 전체 쓰기 차단, 조회만 가능 |

### 3차 결정 반영

- 체험 종료 후 미결제 시에도 데이터는 90일 보관 후 삭제.
- 고지 UI: 프로필 페이지 하단 푸터에 "데이터 처리 기준" 항목을 두고, 클릭 시 보관·삭제 기준 팝업 표시 (사장·직원 공통).

### 남은 세부 사항 (구현 시 확정)

- 해지(CANCELED) 후 데이터 보존 기간 — 다른 이용 종료 상태와 동일하게 90일 적용 권장
- 체험 종료 후 미결제 시 상태 — 뷰어 모드(SUSPENDED 준용) 권장
- 삭제 임박 시 개별 통지 방식과 시점 (이메일/알림, 며칠 전)
- 26일~말일 중간 가입 시 첫 결제 처리 (2절 세부)

## 7. SaaS 구성 요소

### 7.1 데이터 모델 추가 초안 (기획서 16장에 추가)

```text
subscription        계정 구독 (상태, 결제 주기 유형[월간/연간], 다음 결제일, 월 합계 금액)
store_subscription  매장별 부과 항목 (기본 20GB, 매장 요금, 결제 카드[payment_method] 연결)
storage_addon       추가 용량 구매 단위 (10GB x n, 매장 귀속)
payment_method      토스페이먼츠 빌링키 (카드 마스킹 정보) — 계정에 여러 장 등록 가능, 매장마다 다른 카드 지정 가능
invoice             월별 청구서 (일할계산 내역 포함)
payment_history     결제 이력 (성공/실패, 재시도)
storage_usage       매장별 용량 사용량 집계 (사진/파일만)
```

### 7.2 토스페이먼츠

- 정기결제는 토스페이먼츠 "빌링"(빌링키 발급 후 매월 서버 승인) 상품 — 사업자 계약·심사 필요. 현 단계에서는 화면 목업만.
- 목업이라도 실연동 시 구조가 유지되도록 "카드 등록(빌링키 발급)" / "결제 내역" / "다음 결제 예정(매월 25일)" 3요소는 화면에 미리 배치.

### 7.3 법적/운영 필수 항목 (실결제 전 준비)

- 이용약관, 개인정보처리방침, 환불 규정 (연간권 중도 해지: 할인 전 정가 기준 일할 차감 반환 — 2절 확정 규정을 약관에 명시)
- 가격 인상 시 사전 고지 절차
- 세금계산서/현금영수증 발급 — 결제 내역 화면에 발급 버튼 자리 확보

### 7.4 인프라 원가 참고 (2026-07 추정, 서울 리전)

- 매장당 변동비: 저장+전송 월 1,500~4,000원(20GB 헤비유저 상한), 사진 압축 적용 시 1,000원 미만.
- 실수령: 9,900원 - 부가세 - PG 수수료(약 3%) = 약 8,600원 → 매장당 마진 60~85%.
- 고정비: 서버+DB+도메인 월 8~15만원 → 손익분기 유료 매장 약 15~25개.

## 8. 프로필/구독 화면 범위 (목업 단계)

### 공통 프로필 페이지 (`/owner/profile`, `/employee/profile`)

- 아바타, 이름, 연락처, 로그인 정보
- 비밀번호(또는 PIN) 변경
- 진입: 사이드바 하단 사용자 메뉴의 "프로필"
- 페이지 하단 푸터: "데이터 처리 기준" — 클릭 시 보관·삭제 기준(용량 산정 대상, 90일 보관 후 삭제 등) 팝업

### 사장 전용 구독/결제 섹션 (프로필 하위 또는 별도 탭)

- 구독 정보는 **매장별로 구성**한다. 매장마다: 요금(기본/추가 매장), 용량 게이지(20GB+추가분)와 용량 추가 버튼, **매장별 결제 카드**(계정에 등록된 카드 중 지정, 매장마다 다른 카드 가능)와 카드 변경.
- 상단 요약: 월 합계 금액, 매장 수, 다음 결제일(매월 25일), 월간/연간 표시.
- **매장 추가 절차**: 결제가 늘어나는 결정이므로 2중 확인을 거친다.
  1. 경고 팝업: 핵심 고지(월 8,800원·기본 20GB, 즉시 일할계산 결제 + 매월 25일 정기 결제, 해지·환불 기준, 미납 시 제한 흐름) 후 확인 문구("내용을 확인했으며 매장을 추가하겠습니다")를 동일하게 입력해야 진행 가능.
  2. 매장 생성 페이지(4단계, 상단 절차 표시): 매장정보(이름·위치) → 사업장정보(사업자 번호·사업자명·연락처) → 결제등록(카드 선택/등록) → 결제확인(입력 요약 + 오늘 결제 금액 일할계산 + 결제 버튼).
- 결제 내역: 카드별로 승인이 분리되어 기록. 각 건 클릭 시 상세 페이지(결제 일시, 카드, 승인번호, 이용 기간, 항목별 금액, 영수증/세금계산서 버튼).
- 직원 계정에는 구독/결제 정보 일체 미노출 (권한 분리)
