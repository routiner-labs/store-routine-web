# 사장 스케줄 세부검색 확정 동작 설계

## 목표

세부검색 패널에서 이름과 근무시간을 수정하는 동안 기존 검색 결과를 유지하고, 패널의 `검색` 버튼을 눌렀을 때만 두 조건을 함께 적용한다. 헤더와 세부검색 버튼의 화면 텍스트는 모두 짧은 `검색`으로 통일한다.

## 검토한 방식

### 선택: 세부검색 단일 확정 버튼

- 헤더 검색은 직원 이름만 적용한다.
- 세부검색의 `검색`은 직원 이름과 근무시간 초안을 한 번에 적용한다.
- 시간 행의 별도 `근무 시간 적용` 버튼은 제거한다.
- 이름 또는 시간을 수정해도 검색 결과는 즉시 바뀌지 않는다.
- 시작·종료 시간이 모두 비어 있으면 시간 필터를 해제할 수 있다.
- 시간 범위가 불완전하거나 역전되면 세부검색 `검색`을 비활성화한다.

이 방식은 다른 목록 페이지의 세부검색처럼 여러 조건을 정리한 뒤 한 번에 검색한다는 기대와 가장 잘 맞고, 이름과 시간에 서로 다른 확정 버튼이 생기는 혼란을 없앤다.

### 대안 1: 이름 검색과 시간 적용 버튼 유지

현재 구조를 거의 유지할 수 있지만, 사용자가 이름과 시간마다 다른 버튼을 눌러야 하므로 이번 요청의 단일 확정 흐름과 맞지 않는다.

### 대안 2: 입력 즉시 자동 적용

버튼이 필요 없지만, 사용자가 요청한 `검색` 버튼 확정 방식과 반대이며 시간 입력 중 결과가 흔들릴 수 있다.

## 상태와 데이터 흐름

`useEmployeeScheduleFilters`는 기존처럼 입력 초안과 적용값을 분리한다.

- `searchText`, `draftStart`, `draftEnd`: 패널에서 편집 중인 초안
- `appliedSearch`, `appliedStart`, `appliedEnd`: 실제 목록에 적용된 조건
- `applySearch`: 헤더 검색에서 이름만 확정
- `applyAdvancedSearch`: 세부검색에서 이름과 시간 조건을 함께 확정

세부검색 버튼을 누르면 유효한 초안을 적용값으로 복사한다. 시간 입력 두 개가 모두 비어 있으면 적용된 시간 범위를 비우고, 유효한 범위가 있으면 새 범위로 교체한다.

## UI와 접근성

- 헤더 버튼의 화면 텍스트는 `검색`, 접근 가능한 이름은 `헤더 직원 검색`으로 유지한다.
- 세부검색 버튼의 화면 텍스트는 `검색`, 접근 가능한 이름은 `세부검색 검색`으로 지정한다.
- 세부검색 이름 입력에서 Enter를 누르면 세부검색 전체 조건을 적용한다.
- 헤더 이름 입력에서 Enter를 누르면 헤더 이름 검색만 적용한다.
- 시간 오류 안내와 기존 세부검색 활성 스타일은 유지한다.

## 검증

- 헤더와 패널 검색 버튼의 화면 텍스트가 `검색`인지 확인한다.
- 세부검색 이름을 수정한 뒤 버튼을 누르기 전에는 기존 결과가 유지되는지 확인한다.
- 시간 범위를 수정한 뒤 버튼을 누르기 전에는 기존 결과가 유지되는지 확인한다.
- 세부검색 `검색`을 누르면 이름과 시간이 AND 조건으로 함께 적용되는지 확인한다.
- 적용된 시간 범위를 비운 뒤 `검색`을 누르면 시간 필터가 해제되는지 확인한다.
- 불완전하거나 역전된 시간 범위에서는 세부검색 `검색`이 비활성화되는지 확인한다.
- 기존 편집 상태, 날짜별 조정, 저장 영역과 반응형 레이아웃이 유지되는지 확인한다.

## 제외 범위

- 필터 초기화를 초안 전용 동작으로 변경
- 헤더 검색에 근무시간 초안을 함께 적용
- URL에 검색 조건 저장
