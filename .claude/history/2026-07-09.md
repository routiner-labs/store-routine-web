# 2026-07-09

## 매장(구독) 상세 결제 내역 - 해당 구독 청구분만 표시

### 작업한 파일

- `src/mock/subscription.ts`
- `src/app/owner/profile/stores/[id]/page.tsx`

### 변경 이유

구독관리 상세 페이지(매장 상세)의 결제 내역이 매장 기준으로 필터링은 되어 있었지만,
여러 매장이 한 카드로 묶여 결제된 건(예: 신한카드로 강남점+홍대점 합산 18,700원)은
합산 결제 금액이 그대로 노출되어 다른 매장 요금까지 섞여 보였다.
해당 구독(매장)에 대한 결제 내역만 보이도록 개선.

### 주요 결정 사항

- `PaymentItem`에 `storeId` 필드를 추가해 결제 항목이 어느 매장 청구분인지 명시.
  (기존에는 항목 label 문자열에만 매장명이 있어 매장 매칭이 불가능했음)
- 매장 상세의 결제 내역 행 금액은 `record.amount`(합산액) 대신
  해당 매장 `storeId`와 일치하는 items 합계(`storeAmount`)로 표시.
  - 강남점: 18,700원 → 9,900원, 홍대점: 18,700원 → 8,800원
  - 신촌점은 단독 결제라 변동 없음
- 행 클릭 시 이동하는 결제 상세 페이지(`payments/[id]`)는 실제 카드 승인 단위 영수증이므로
  합산 금액/전체 항목 표시를 유지.
- 프로필 메인·결제 내역 목록 페이지는 계정 전체 결제 내역이므로 변경하지 않음.

### 화면/기능

- 프로필 → 매장별 구독 → 매장 상세 → 결제 내역: 해당 매장 청구분 금액만 표시
