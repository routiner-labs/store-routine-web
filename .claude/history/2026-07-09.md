## 매장(구독) 상세 결제 내역 - 해당 구독 청구분만 표시

### 작업한 파일

- `src/mock/subscription.ts`
- `src/app/owner/profile/stores/[id]/page.tsx`

### 변경 이유

구독관리 상세 페이지(매장 상세)의 결제 내역이 매장 기준으로 필터링은 되어 있었지만,
여러 매장이 한 카드로 묶여 결제된 건(예: 신한카드로 강남점+홍대점 합산 18,700원)은
합산 결제 금액이 그대로 노출되어 다른 매장 요금까지 섞여 보였다.
해당 구독(매장)에 대한 결제 내역만 보이도록 개선.

### 주요 결정 사항

- `PaymentItem`에 `storeId` 필드를 추가해 결제 항목이 어느 매장 청구분인지 명시.
  (기존에는 항목 label 문자열에만 매장명이 있어 매장 매칭이 불가능했음)
- 매장 상세의 결제 내역 행 금액은 `record.amount`(합산액) 대신
  해당 매장 `storeId`와 일치하는 items 합계(`storeAmount`)로 표시.
  - 강남점: 18,700원 → 9,900원, 홍대점: 18,700원 → 8,800원
  - 신촌점은 단독 결제라 변동 없음
- 행 클릭 시 이동하는 결제 상세 페이지(`payments/[id]`)는 실제 카드 승인 단위 영수증이므로
  합산 금액/전체 항목 표시를 유지.
- 프로필 메인·결제 내역 목록 페이지는 계정 전체 결제 내역이므로 변경하지 않음.

### 화면/기능

- 프로필 → 매장별 구독 → 매장 상세 → 결제 내역: 해당 매장 청구분 금액만 표시

## 업무리스트 - 테스크 목록에 휴지통 아이콘 추가 (드래그로 비활성화)

### 작업한 파일

- `src/app/owner/checklists/page.tsx`
- `src/app/owner/checklists/page.module.css`

### 변경 이유

테스크 목록(카탈로그)에서 안 쓰는 테스크를 빠르게 정리할 방법이 없었다.
기존에는 테스크 관리 팝업을 열어 상태를 비활성으로 바꿔야 했는데,
테스크 목록 패널에 휴지통 드롭 타겟을 두어 끌어다 놓는 것만으로 비활성화되도록 개선.

### 주요 결정 사항

- 삭제가 아니라 비활성화(`active: false`)로 처리. 카탈로그 목록에서는 사라지지만
  테스크 관리 팝업에서 비활성 뱃지로 남아 있고 언제든 다시 활성화 가능.
- 되돌릴 수 있는 동작이므로 컨펌 창 없이 토스트로만 알림
  (컨펌 규칙은 실제 삭제 버튼에만 적용).
- 위치는 패널 하단 드롭존으로 만들었다가 피드백 받아 "테스크 목록" 제목 오른쪽
  아이콘만 배치하는 방식으로 변경. 마우스 오버 시 기존 InfoTip 툴팁 스타일
  (`.infoTooltip`/`.infoTooltipRight`)을 재사용해 휴지통 설명 표시.
- 카탈로그 테스크를 드래그하는 동안 danger 톤으로 강조, 아이콘 위에 올리면 danger 배경으로 반전.
- 색상은 전부 CSS 토큰(`--color-danger`, `--color-danger-light` 등)만 사용해 다크 모드 대응.
- 이미 날짜별 리스트에 추가된 업무는 건드리지 않음(테스크 관리에서 비활성화할 때와 동일한 동작).

### 화면/기능

- 업무리스트 → 테스크 목록 제목 오른쪽: 휴지통 아이콘 (호버 시 툴팁, 테스크 드래그 앤 드롭 시 비활성화 + 토스트)

## 업무리스트 - 테스크 관리 목록에 활성/비활성 온오프 스위치 추가

### 작업한 파일

- `src/app/owner/checklists/page.tsx`
- `src/app/owner/checklists/page.module.css`

### 변경 이유

테스크 관리 팝업에서 테스크를 비활성화하려면 항목을 선택한 뒤 상세 폼의
상태(활성/비활성) 세그먼트를 바꾸고 저장해야 했다. 목록에서 바로 켜고 끌 수 있도록
각 항목 오른쪽에 온오프 스위치를 추가.

### 주요 결정 사항

- 스위치 클릭 시 즉시 반영(저장 버튼 불필요) + 토스트 알림. `stopPropagation`으로
  항목 선택과 분리.
- 기존 "비활성" 뱃지는 스위치가 상태를 대신 보여주므로 제거(`offBadge` 스타일 삭제).
  비활성 항목의 뱃지·이름 흐림 처리는 유지, 스위치는 흐리지 않아 상태 식별 가능.
- 현재 편집 중인 테스크를 토글하면 상세 폼의 상태 세그먼트(`newActive`)도 동기화.
- 목록 항목이 `<button>`이었는데 스위치 버튼을 중첩할 수 없어(HTML 유효성)
  `<div>` + onClick으로 변경. 기존 스타일 그대로 적용됨.
- 스위치는 iOS 스타일 트랙+노브. 온 상태는 `--color-primary`, 오프는 `--color-border`
  토큰 사용으로 다크 모드 대응.

### 화면/기능

- 업무리스트 → FAB → 테스크 관리 → 좌측 목록: 항목별 활성/비활성 온오프 스위치

## 업무리스트 - 휴무자 제외 접힘 애니메이션 + 배정 1명도 팝업 표시

### 주요 결정 사항

- 애니메이션은 `setTimeout` 없이 CSS 전환으로 처리(프로젝트 규칙). 휴무 카드를
  목록에서 제거하지 않고 항상 렌더한 뒤 `empCardHidden` 클래스로 접는다.
  - `filteredEmployees`는 다시 검색 전용으로 되돌리고, 카드별로 `hidden = hideOffDuty && 휴무`
    계산해 클래스/`draggable`/`aria-hidden` 적용(숨김 카드는 `pointer-events:none`으로 드래그 차단).
  - 접힘 시 여백까지 함께 사라지도록 `.empList`의 `gap`을 카드 `margin`으로 전환
    (모바일=가로 `margin-right`, 데스크톱=세로 `margin-bottom`, 각 `:last-child` 리셋).
  - 접힘 축이 방향별로 달라 모바일은 `max-width:0`, 데스크톱(≥768px 세로 목록)은 `max-height:0`
    + 상하 패딩 0. 공통으로 opacity/scale(0.85)/border-width 0. 0.22s ease.
  - 원래 `.empCard`의 hover용 `transition`(border-color/box-shadow)을 실수로 옮기지 않도록
    접힘 속성과 합쳐 한 줄로 정리.
- 배정 표시: `assigneeIds.length === 1` 인라인 칩 블록 제거, `>= 2` → `>= 1`로 변경.
  이제 1명도 트리거 + 호버 툴팁 카드(제거 버튼 포함)로 표시.
  더는 안 쓰는 `.assigneeChip`/`.assigneeAvatar`/`.assigneeRemove` CSS 제거.
- 트리거 뱃지 텍스트: 'N명 배정' → 1명이면 이름, 2명 이상이면 '이름 외 N'(첫 배정자 기준).
  뱃지는 호버 트리거라 프로필 팝업이 겹치지 않게 `EmployeeName` 대신 일반 텍스트로 이름 표시.

### 화면/기능

- 업무리스트 → '휴무자 제외' 토글 시 카드가 접히며 사라짐/나타남(양방향)
- 업무리스트 → 배정 뱃지: 1명이면 이름, 2명 이상이면 '이름 외 N' (호버 시 전체 목록 팝업)

## 업무리스트 - 테스크 목록 클릭 시 드롭다운(관리/비활성화)

### 작업한 파일

- `src/app/owner/checklists/page.tsx`
- `src/app/owner/checklists/page.module.css`

### 변경 이유

테스크 목록(카탈로그)의 테스크는 드래그로만 다룰 수 있어, 관리 화면으로 가거나
비활성화하려면 FAB나 휴지통을 따로 써야 했다. 항목을 클릭하면 바로
'관리 / 비활성화' 드롭다운이 뜨도록 추가.

### 주요 결정 사항

- 기존 업무 카드 드롭다운(`taskMenu`/`taskMenuItem`/`taskMenuIcon`/`menuOverlay`) 스타일을 재사용.
- `catalogMenuId` 상태로 열린 항목 추적. 항목 클릭 시 토글, 바깥 클릭 오버레이로 닫힘.
  드래그(리스트/휴지통에 끌어놓기)는 그대로 — 드래그는 click 이벤트를 발생시키지 않아 공존.
- '관리' → `openManageFor(tpl)`: 해당 테스크를 선택한 상태로 테스크 관리 모달 오픈.
- '비활성화' → 기존 `deactivateTask(tpl.id)` 재사용(active:false + 토스트). 아이콘은 `LiaBanSolid`
  (삭제가 아니므로 휴지통 아이콘 대신 금지 아이콘).
- 메뉴 앵커를 위해 `.catalogItem`에 `position: relative` 추가, 열린 항목은 `catalogItemActive`로 강조.
- 드롭다운 폭은 항목 폭과 동일하게(`.catalogMenu { width:100%; min-width:0 }`). 공용 `.taskMenu`의
  `min-width:160px`를 덮어쓰되, 업무 카드 메뉴에는 영향 없도록 카탈로그 전용 클래스로 분리.
- 버그 수정: 데스크톱에서 `.catalogPanel`이 `position:sticky`라 자체 stacking context를 만들어,
  전체화면 오버레이(z45, 루트)가 패널 안 메뉴(z46)보다 위로 올라가 메뉴 클릭이 막혔음.
  오버레이 방식을 버리고 `document` `pointerdown` 리스너로 바깥 클릭 감지(`catalogItem` 바깥이면 닫힘).
  드래그 시작 시에도 메뉴 닫음.
- '비활성화'는 컨펌 후 실행하도록 변경. `confirmDeactivate(tpl)`: 메뉴 닫고 공용 `confirm()`
  (확인 '비활성화'/취소, `danger:false`) → 확인 시 `deactivateTask`. 휴지통 드래그 경로는 기존대로 즉시.

### 화면/기능

- 업무리스트 → 테스크 목록 항목 클릭 → '관리 / 비활성화' 드롭다운
- 업무리스트 → 드롭다운 '비활성화' 클릭 시 컨펌 팝업
