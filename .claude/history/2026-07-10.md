## RichTextEditor - 삽입 이미지 가로 크기 조절

### 작업 파일
- `src/components/RichTextEditor/RichTextEditor.tsx` + `.module.css`

### 변경 이유
글쓰기 에디터(문서 작성/수정, 테스크 수행방법)에서 이미지를 넣으면 크기 조절이 안 됐음 → 드래그로 가로 폭 조절 가능하게.

### 주요 변경
- `ImageNode`에 `__width?`(px) 추가: `setWidth`, JSON(import/export)·`exportDOM`(있으면 `style="width:Npx"`)·`importDOM`(style/attr에서 px 파싱) 반영. 폭 없는 기존 이미지는 원본 크기 유지(하위호환).
- `decorate()`가 새 `ResizableImage` 컴포넌트를 렌더 — 우하단 드래그 핸들(호버 시 노출) + 호버 아웃라인. 드래그 중엔 리렌더 없이 DOM(style.width/class)을 직접 조작해 라이브 프리뷰, `pointerup`에서만 `editor.update`로 노드에 폭 커밋(스냅백/불필요 히스토리 방지). 폭은 48px~에디터폭으로 clamp.
- 저장 HTML에 `width`가 인라인으로 들어가므로 문서 뷰어(문서 상세/방법 팝업/참조문서 뷰어)는 별도 수정 없이 반영. 뷰어 img의 `max-width:100%`로 좁은 화면 반응형 유지.
- setState-in-effect/스냅백 회피를 위해 드래그 상태를 React state로 두지 않고 imperative DOM 방식 채택.

### 검증
- `tsc`/`eslint` 통과, 에디터·뷰어 4개 라우트 200. 실제 드래그 리사이즈는 브라우저에서 확인 필요(드라이버 부재).

### 후속(버그픽스): 컨펌창이 팝업 뒤에 뜨는 문제
- 증상: 요청함 요청상세의 '테스크 추가'(guard) 팝업에서 ESC 시 컨펌창이 팝업 뒤에 떠서 안 보임.
- 원인: `ConfirmContext` 오버레이 z-index가 500인데, 요청상세 내부 팝업 오버레이(`RequestDetailView.module.css .popupOverlay`)는 600이라 컨펌이 뒤로 감. (프로필 700, 알림 1200 등도 500보다 큼)
- 수정: 컨펌 오버레이 z-index를 500 → 9000으로 상향(토스트 9999만 위). 레이아웃상 프로바이더는 DOM 래퍼가 없어 컨펌창이 body 직속 최상위 스태킹에 위치하므로, 모든 팝업 위에 뜬다. 전 guard 팝업에 동일하게 적용됨.
