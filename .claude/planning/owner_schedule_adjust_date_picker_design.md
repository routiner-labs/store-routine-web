# 사장 스케줄 일자별 조정 달력 설계

## 목표

일자별 조정 화면의 네이티브 날짜 입력을 업무리스트 상단 날짜 버튼을 눌렀을 때 열리는 월간 팝업 달력과 같은 형태로 변경한다.

## 기준 화면

`owner/checklists` 업무리스트의 상단 날짜 선택 UI를 기준으로 한다.

- 날짜 버튼: `6월 30일 (화)` 형식과 아래 방향 아이콘
- 팝업: 선택 날짜 버튼 아래에 나타나는 작은 월간 달력 카드
- 헤더: 이전 달, `2026년 6월`, 다음 달
- 달력: 월요일 시작 7열, 토요일 primary 색상, 일요일 danger 색상
- 상태: 오늘은 강조 글자, 선택일은 primary 원형 배경
- 날짜를 선택하면 즉시 적용하고 팝업을 닫음

## 검토한 방식

### 선택: 스케줄 전용 달력 컴포넌트

`EmployeeScheduleDatePicker`를 새로 만들고 업무리스트 달력의 시각 언어와 상호작용을 동일하게 구현한다.

- 장점: 업무리스트의 큰 페이지 파일을 수정하지 않고 요구 범위만 안전하게 변경한다.
- 장점: 300줄 제한에 도달한 `EmployeeScheduleManager`에 달력 상태와 마크업을 추가하지 않아도 된다.
- 단점: 업무리스트와 달력 로직 일부가 중복되지만 현재 단일 사용 범위에서는 허용 가능한 수준이다.

### 대안 1: 업무리스트 달력을 공용 컴포넌트로 추출

두 화면의 장기 일관성은 가장 높지만 업무리스트의 상태·데이터 초기화 로직과 로컬 CSS까지 함께 수정해야 해서 이번 요청보다 범위가 커진다.

### 대안 2: 날짜 범위 필터 재사용

`DateRangeFilter`는 두 날짜 범위와 연월 다이얼을 위한 컴포넌트라 단일 날짜 선택에 불필요한 동작이 포함된다.

## 컴포넌트 구조

### `EmployeeScheduleDatePicker`

```ts
type EmployeeScheduleDatePickerProps = {
  value: string
  today: string
  onChange: (value: string) => void
}
```

- `value`의 연·월로 팝업의 초기 월을 설정한다.
- 팝업을 다시 열면 이전에 탐색만 했던 월이 아니라 현재 선택 날짜의 월로 돌아간다.
- 날짜 선택 시 `YYYY-MM-DD` 형식으로 `onChange`를 호출하고 즉시 닫는다.
- 이전·다음 달 이동은 선택값을 변경하지 않는다.
- 12월과 1월 사이의 연도 이동을 지원한다.

`EmployeeScheduleManager`는 기존 `schedDate`와 `setSchedDate`를 그대로 제공한다. 날짜가 바뀌면 기존 `effectiveDay`와 시간 필터가 새 날짜 기준으로 다시 계산되는 동작을 유지한다.

## 배치와 디자인

- 현재 `dateRow`의 첫 번째 항목을 네이티브 입력에서 날짜 버튼으로 교체한다.
- 버튼은 primary 글자, 작은 아래 아이콘, hover 시 primary-light 배경을 사용한다.
- 팝업은 버튼 아래 왼쪽에 정렬한다. 모바일에서도 좌우 화면 여백 16px 안에 들어오도록 최대 폭을 제한한다.
- 카드 크기, 14px 모서리, 여백, 7열 그리드, 선택일 원형 강조는 업무리스트 달력과 동일하게 맞춘다.
- 모든 표면·보더·텍스트·강조 색상은 기존 CSS 토큰을 사용해 다크모드를 지원한다.
- 390px에서도 가로 넘침이 없고 하단 저장 영역과 편집표 배치를 바꾸지 않는다.

## 닫기와 접근성

- 투명한 바깥 클릭 영역을 누르면 선택을 바꾸지 않고 닫는다.
- 가벼운 선택 팝오버이므로 ESC를 누르면 확인창 없이 닫는다.
- 날짜 버튼은 `조정 날짜`, `aria-expanded`, `aria-haspopup`, `aria-controls`를 제공한다.
- 팝업은 `조정 날짜 선택` 이름의 dialog 역할을 가진다.
- 월 이동 버튼은 `이전 달`, `다음 달` 이름을 가진다.
- 날짜 버튼은 `2026년 7월 1일 선택`처럼 전체 날짜 이름을 제공한다.
- 선택 날짜는 `aria-pressed`, 오늘 날짜는 `aria-current="date"`로 전달한다.

## 검증

- 초기 버튼에 `6월 30일 (화)`가 표시되는지 확인한다.
- 버튼을 누르면 2026년 6월 달력이 열리고 30일이 선택 상태인지 확인한다.
- 다음 달로 이동해 7월 1일을 선택하면 버튼이 `7월 1일 (수)`로 바뀌고 팝업이 닫히는지 확인한다.
- 날짜를 바꾸면 일자별 조정 행과 적용된 근무시간 필터가 새 날짜 기준으로 다시 계산되는지 확인한다.
- 이전·다음 달 이동만으로는 선택 날짜가 바뀌지 않는지 확인한다.
- 바깥 클릭과 ESC로 닫을 때 선택 날짜가 유지되는지 확인한다.
- 1440px, 768px, 390px의 라이트·다크 모드에서 팝업 위치, 선택일, 주말 색상과 가로 넘침을 확인한다.

## 제외 범위

- 업무리스트 달력 자체 리팩터링
- 날짜 범위 선택
- 연·월 스크롤 다이얼
- 조정 내용을 날짜 간 복사
